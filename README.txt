ویدیو‌یار AI — نسخه اولیه وب‌سایت

انتشار رایگان با GitHub Pages از گوشی:
1) وارد github.com شو و یک مخزن (Repository) جدید بساز.
2) نام مخزن را video-yar-ai بگذار و Public انتخاب کن.
3) در مخزن روی Add file > Upload files بزن.
4) فایل index.html را از این بسته بارگذاری کن و Commit changes بزن.
5) در Settings > Pages، بخش Build and deployment را روی Deploy from a branch بگذار.
6) Branch را main و پوشه را /(root) انتخاب کن و Save بزن.
7) چند دقیقه صبر کن؛ آدرس سایت معمولاً این قالب را دارد:
   https://نام‌کاربری.github.io/video-yar-ai/

یادداشت:
- این نسخه در حال حاضر سناریو و پرامپت آماده می‌کند و عکس را فقط در مرورگر پیش‌نمایش می‌دهد.
- برای تولید واقعی ویدیوی AI یا پاسخ هوشمند آنلاین، باید یک سرویس API مناسب وصل شود.
- کلید API را داخل index.html قرار نده؛ برای محافظت از کلید باید بک‌اند امن استفاده شود.
